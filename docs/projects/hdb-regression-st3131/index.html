HDB Resale Price Regression Model

A statistically rigorous linear model of Singapore HDB resale prices that explains 88.6% of price variation.

Overview

The goal was to build the best possible linear regression model for HDB resale prices that also satisfies the standard regression assumptions, so its coefficients can be trusted and interpreted. The data covers 2,456 resale transactions from July 2020 (data.gov.sg).

What I did

  1. Explored the price distribution (right-skewed, skewness 1.04) and engineered features: remaining lease in decimal years, storey midpoints and flat age.
  2. Detected perfect multicollinearity between remaining lease, flat age and lease start date (|r| = 0.9993) and kept only one of them.
  3. Fitted a baseline model, then used Box-Cox analysis (optimal λ = −0.38) to compare log and reciprocal square-root transformations, choosing the log for interpretability.
  4. Ran stepwise AIC selection, VIF checks, influence diagnostics (Cook's distance) and full residual checks for normality, constant variance, linearity and independence.
  5. Interpreted every coefficient as a percentage price effect, e.g. +0.89% per extra square metre and a 43% premium for the Central Area.

Results

  • Adjusted R² of 0.886, up from 0.841 for the untransformed baseline
  • Average prediction error (MAPE) of 8.62%
  • All regression assumptions checked and satisfied; no highly influential points
